🎯 Core Features

👁️

Gaze Tracking

WebGazer.js untuk pelacakan mata berbasis webcam. Kalibrasi 9-point dengan akurasi 75%+. Real-time tracking 10Hz.

🎤

Speech Analysis

Web Speech API untuk analisis ucapan bahasa Indonesia. Pronunciation assessment & fluency metrics.

🤖

AI Assessment

Machine Learning models (Random Forest + Gradient Boosting). 4-level difficulty classification dengan 85-90% accuracy.

📚

Adaptive Learning

Personalized learning paths berdasarkan assessment. Dynamic difficulty adjustment & material recommendation.

👨‍🎓

Student Dashboard

Assessment session, progress tracking, achievements system. Interactive & gamified.

👨‍🏫

Teacher Dashboard

Class management, student monitoring, intervention scheduling, feedback system, analytics.

👨‍👩‍👧

Parent Dashboard

Child progress monitoring, home practice recommendations, parent-friendly insights.

👤

Admin Dashboard

User management (CRUD), system monitoring, statistics, bulk operations.

🚀 How to Run Locally

📍 Location: C:\CAPSTONE\CORTEXIA

Quick Start:

2. Run: .\setup-database.ps1 (one time only)
3. Run: .\START-ALL.ps1
4. Wait 60 seconds
5. Browser will open to http://localhost:3000
